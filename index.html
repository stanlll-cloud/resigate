让 AI 与风控网站固定走你的静态住宅 IP

日常流量照常走高速机场，仅将 Claude、ChatGPT、Gemini、Stripe 与验证码精确分流到住宅出口；全流程本地浏览器生成，不上传任何账密。

1 填入静态住宅代理信息

支持直接粘贴整串代理（如 host:port:user:pass、user:pass@host:port 或 http://...），会自动拆解。

代理协议：
高级选项（自定义跳板 / UDP / IPv6 防 502）
请填写完整的住宅代理地址、端口、用户名和密码。

2 选择需要走住宅 IP 的场景

默认仅勾选高频 AI 与支付风控域名，避开 Google Drive / Play 等大流量下载，帮你省下住宅流量。

自定义补充域名或规则（可选）

3 选择客户端并导出配置

选好你的设备客户端，直接「复制」或「下载文件」导入即可。

小火箭节点导入

用 iPhone 小火箭扫码添加 🏠住宅出口-勿选 节点，随后配置前置代理并导入下方分流模块。

请先在第一步填写完整的住宅代理信息。

4 验证出口 IP 是否生效

配置生效后，访问检测网站核对显示的 IP 是否与你购买的静态住宅 IP 一致。

1. 浏览器访问 ipv4.webshare.io 或 ipinfo.io/json，确认显示的 IP 与归属地无误。

2. 终端 / Claude Code 用户需开启客户端 TUN 模式，或在终端设置代理变量（如 export HTTPS_PROXY=http://127.0.0.1:7890）后运行：

curl -s https://ipv4.webshare.io/
